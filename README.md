# tahoe-weather-analysis-STA141B
Statistical Analysis of Weather Patterns for Popular Tahoe Ski Resorts

Authors: Mark Chao, Cody Brown, Natalie Alvarez
Class: STA 141B Data & Web Technologies for Data Analysis, FQ 2025, Nicolai Amann

Using Lake Tahoe historical weather data, we aimed to be able to identify temperature and snowfall trends, along with seasonal changes through Tahoe's winter. Our analysis uses techniques learned in our class to create a practical climate forecast for ski resorts to use in the winder to optimize their business model.

Data: Open-Mateo Historical Weather API
